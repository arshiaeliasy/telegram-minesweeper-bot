## 🎯 این ربات چه‌کار می‌کند؟

یک ربات کامل **مین‌روب (Minesweeper)** برای تلگرام با دو حالت:

| حالت | کجا | توضیح |
| --- | --- | --- |
| ⚔️ **دوئل دونفره** (اصل بازی) | گروه | دو نفر روی یک تختهٔ مشترک، نفرِ به نوبت بازی می‌کنند و نتیجه در **جدول امتیازات همان گروه** ثبت می‌شود. |
| 🎮 **تک‌نفره** | چت خصوصی یا گروه | برای تمرین و ثبت رکورد شخصی. |

هدف دوئل برعکسِ مین‌روب کلاسیک است: **بمب پیدا کن، امتیاز بگیر!**

> 💡 ربات فقط با **کتابخانهٔ استاندارد پایتون** نوشته شده — نه `pip install` لازم است، نه دیتابیس، نه وب‌سرور.

## ✨ ویژگی‌ها

- ⚔️ **دوئل دونفرهٔ واقعی در گروه** — یک تختهٔ مشترک، نوبت‌گردشی، برد/باخت/مساوی.
- 💣 **امتیاز بمب** — با پیدا کردن مین یک امتیاز می‌گیری و **دوباره نوبت خودت** است.
- 🏆 **جدول امتیازات هر گروه** — برد/باخت، نرخ برد، تاریخچهٔ آخرین ۳۰ دوئل و آمار **رودررو**.
- 🎮 **بازی تک‌نفره** با سه سطح، حالت پرچم‌گذاری، chord و بهترین زمان‌ها (`/top`).
- 🔁 **دوئل مجدد** با یک دکمه؛ نفر شروع‌کننده عوض می‌شود.
- 🧩 **چند دعوت و چند دوئل همزمان** در یک گروه؛ هر دوئل تخته و پیام خودش را دارد.
- ⏱ **تایم‌اوت خودکار** — ۱۰ دقیقه بی‌حرکتی ⇒ پایان بازی و مقایسهٔ بمب‌ها.
- 🏳️ **تسلیم** با `/surrender`.
- 🛡 **اولین کلیک امن** — مین‌ها بعد از اولین کلیک کاشته می‌شوند.
- ⚙️ **پشتیبانی از تاپیک گروه (Forum)** — با `/topic` همهٔ پیام‌ها به یک تاپیک ثابت می‌روند.
- 🧵 **چند تردی** — پردازش آپدیت‌ها با `ThreadPoolExecutor` (بدون بلاک شدن روی کلیک‌های همزمان).
- 💾 **ذخیرهٔ اتمیک آمار** در JSON (نوشتن در فایل موقت + `replace`؛ مقاوم به کرش).
- 🧪 **۱۱۵ تست** بدون نیاز به توکن یا اینترنت.
- 🇮🇷 **رابط کاملاً فارسی** با رقم‌های فارسی، ساعت و تاریخ فارسی، و منشن‌های امن (escape شده).

## ⚔️ دوئل چطور کار می‌کند؟

1. در گروه بنویس `/duel` (یا `/duel متوسط`) → ربات یک **دعوت‌نامهٔ دوئل** می‌فرستد.
2. نفر دوم روی **🎯 پیوستن به دوئل** می‌زند → بازی شروع می‌شود.
3. بازیکنان **نفرِ به نوبت** یک خانه باز می‌کنند (هدف: **پیدا کردن بمب**):
   - 💣 اگر **مین (بمب)** پیدا کنند یک امتیاز می‌گیرند و **دوباره نوبت خودشان** است.
   - 🔢 اگر **خانهٔ امن** باز کنند، عددِ مین‌های اطراف نمایش داده می‌شود و **نوبت به حریف می‌رود**.
   - 🏆 وقتی همهٔ مین‌ها پیدا شوند بازی تمام می‌شود؛ هرکس **بمب بیشتری** پیدا کرده **برنده** است (مساوی = مساوی).
   - ⏱ اگر **۱۰ دقیقه** هیچ‌کس کلیک نکند، بازی **خودکار تمام** و بمب‌ها مقایسه می‌شوند.
   - 🏳️ تسلیم با `/surrender` (تسلیم‌کننده می‌بازد).
4. 🏆 نتیجه و **رودررو (head-to-head)** همان لحظه در پیام بازی و در جدول گروه ثبت می‌شود.
5. 🔁 با دکمهٔ «دوئل مجدد» همان دو نفر دوباره بازی می‌کنند (نفر شروع‌کننده عوض می‌شود).
6. 🎮 **چند دعوت و چند دوئل همزمان** در یک گروه مجاز است؛ هر دوئل تخته و پیام خودش را دارد.

**قواعد ایمنی:** دعوت‌نامه **۱۵ دقیقه** اعتبار دارد، فقط سازندهٔ دوئل می‌تواند سطح را عوض کند یا لغو کند، تماشاچی‌ها نمی‌توانند روی تخته بزنند، و **اولین کلیک هر بازی امن است** (مین‌ها بعد از اولین کلیک کاشته می‌شوند و زیر آن خانه و ۸ خانهٔ اطرافش مین نیست).

## 🚀 راه‌اندازی سریع

### ۰) پیش‌نیاز

فقط **پایتون ۳.۹ یا بالاتر** (روی ۳.۱۴ تست شده). هیچ پکیجی لازم نیست:

```bash
python --version   # باید 3.9+ باشد
```

### ۱) توکن ربات

از [@BotFather](https://t.me/BotFather) توکن بگیر و یکی از این سه راه را انتخاب کن:

| راه | دستور |
| --- | --- |
| الف) فایل توکن | فایل `token.txt.example` را به `token.txt` تغییر نام بده و توکن را داخلش بگذار |
| ب) متغیر محیطی | `set BOT_TOKEN=123456:ABC-DEF...` (ویندوز) یا `export BOT_TOKEN=...` (لینوکس/مک) |
| ج) خط فرمان | `python bot.py --token 123456:ABC-DEF...` |

```bash
# کلون و اجرا
git clone https://github.com/arshiaeliasy/telegram-minesweeper-bot.git
cd telegram-minesweeper-bot

# فایل توکن را بساز
cp token.txt.example token.txt      # لینوکس/مک
copy token.txt.example token.txt    # ویندوز
# سپس توکن خودت را داخل token.txt بگذار

python bot.py
```

یا با اسکریپت آماده:

```bat
run.bat            :: ویندوز
```
```bash
./run.sh           # لینوکس / مک
```

> ⚠️ فایل `token.txt` و `stats.json` در `.gitignore` هستند و **هرگز** نباید کامیت شوند.

### ۲) بازی در گروه

1. ربات را به یک **گروه** اضافه کن.
2. در گروه بنویس `/duel`.
3. نفر دوم روی «🎯 پیوستن به دوئل» بزند.
4. تمام! جدول گروه با `/score`.

> اگر ربات در گروه به پیام‌های معمولی جواب نمی‌دهد طبیعی است؛ ربات‌ها به‌طور پیش‌فرض
> فقط **دستورها** و **دکمه‌ها** را می‌بینند. همهٔ امکانات این ربات با دستور و دکمه کار می‌کند.
> در گروه‌های شلوغ بهتر است دستور را با یوزرنیم بزنی: `/duel@YourBot`.

## 🕹 دستورها

| دستور | مترادف‌ها | کار |
| --- | --- | --- |
| `/duel` یا `/duel متوسط` | `/دوئل` | ساخت دعوت‌نامهٔ دوئل در گروه (سطح: `آسان`/`متوسط`/`سخت`) |
| `/join` | `/پیوستن` | پیوستن به دعوت‌نامه (جای دکمه؛ اگر چند دعوت باز باشد فهرست می‌دهد) |
| `/cancel` | `/لغو` | لغو دعوت‌نامه (فقط سازنده؛ اگر چندتا باشد فهرست می‌دهد) |
| `/surrender` | `/resign` · `/تسلیم` | تسلیم شدن در دوئل جاری (اگر در چند دوئل باشی فهرست می‌دهد) |
| `/score` | `/table` · `/جدول` · `/امتیازات` | 🏆 جدول امتیازات و تاریخچهٔ همین گروه |
| `/topic` | `/تاپیک` · `/موضوع` | ⚙️ ثبت همین تاپیک به‌عنوان تاپیک ثابت ربات (فقط مدیر گروه)؛ `/topic off` برای حالت خودکار |
| `/stats` | `/آمار` | 📊 آمار شخصی (تک‌نفره + دوئل + رتبه در گروه) |
| `/solo` | `/new` · `/تکنفره` | 🎮 بازی تک‌نفره (در گروه، منوی دوئل را نشان می‌دهد) |
| `/top` | `/برترین` | برترین زمان‌های تک‌نفره |
| `/help` | `/راهنما` | راهنمای کامل |
| `/start` | — | شروع (منوی سطح در چت خصوصی، منوی دوئل در گروه) |

**نمادهای تخته:** 🟦 پوشیده · ⬜ خالی · 1️⃣..8️⃣ تعداد مین اطراف · 🚩 پرچم · 💣 مین ·
💥 مین منفجرشده · ❌ پرچم اشتباه

**سطوح بازی:**

| سطح | کلید | تخته | مین |
| --- | --- | --- | --- |
| 🙂 آسان | `easy` | ۶×۶ | ۶ |
| 😐 متوسط | `medium` | ۸×۸ | ۱۲ |
| 😈 سخت | `hard` | ۹×۹ | ۲۰ |

## 🏆 جدول امتیازات گروه

برای هر گروه جداگانه ذخیره می‌شود:

* تعداد دوئل‌ها و بازیکن‌ها
* برد/باخت و نرخ برد هر بازیکن (مرتب بر اساس برد)
* **تاریخچهٔ آخرین دوئل‌ها**: چه کسی، با چه کسی، در چه سطحی، چقدر زمان، چه روزی
* آمار **رودررو** دو بازیکن (آرش ۳ — ۲ سارا)

نمونه:

```text
🏆 جدول امتیازات این گروه
👥 گروه رفقا
🎮 دوئل‌های انجام‌شده: ۱۲ | 👤 بازیکن‌ها: ۴

🥇 آرش — ۵ برد / ۱ باخت (۸۳٪)
🥈 سارا — ۳ برد / ۴ باخت (۴۳٪)
🥉 نوید — ۱ برد / ۰ باخت (۱۰۰٪)

📜 آخرین دوئل‌ها
• امروز ۱۱:۳۴ — آرش 🏆 سارا (متوسط، ۰:۵۲)
• دیروز ۲۱:۰۵ — سارا 🏆 نوید (آسان، ۰:۱۸)
```

## ⚙️ تاپیک گروه (سوپراگروه فروم)

اگر گروهت چند تاپیک دارد (مثل «اطلاع‌رسانی» و «چت آزاد»)، ربات به‌طور پیش‌فرض
در همان تاپیکی جواب می‌دهد که پیام یا دکمه از آن آمده است. برای اینکه همهٔ پیام‌های
ربات همیشه در یک تاپیک ثابت (مثلاً «چت آزاد») بیایند:

1. به‌عنوان **مدیر گروه** وارد تاپیک دلخواه شو.
2. همان‌جا دستور `/topic` را بفرست.
3. پیام تأیید ربات در همان تاپیک می‌آید؛ از این به بعد همهٔ پیام‌ها همان‌جا می‌روند.
4. برای برگشت به حالت خودکار: `/topic off`.

> لازم نیست ربات را از تاپیک «اطلاع‌رسانی» حذف و دوباره اد کنی؛ فقط دستور `/topic`
> را در تاپیک «چت آزاد» بزن. اگر ربات را در تاپیک اشتباه اد کرده‌ای، همین کافی است.

## 🧰 گزینه‌های اجرا

| گزینه | پیش‌فرض | کار |
| --- | --- | --- |
| `--token`, `-t` | — | توکن ربات |
| `--token-file` | `token.txt` | فایل حاوی توکن |
| `--stats-file` | `stats.json` | محل ذخیرهٔ آمار |
| `--poll-timeout` | `25` | زمان انتظار long-polling (ثانیه) |
| `--workers` | `8` | تعداد تردهای پردازش آپدیت |
| `--verbose`, `-v` | خاموش | لاگ کامل |

```bash
python bot.py --token 123456:AAE...        # توکن روی خط فرمان
python bot.py -v                           # لاگ کامل
python bot.py --stats-file /data/stats.json --workers 16
```

## 🚢 دیپلوی

چون هیچ وابستگی‌ای وجود ندارد، دیپلوی خیلی ساده است. فقط یادت باشد **توکن** را از

<details>
<summary><b>🐳 داکر (توصیه‌شده)</b></summary>

```bash
docker build -t minesweeper-bot .

  -e BOT_TOKEN=123456:ABC-DEF... \
  -v minesweeper-data:/data \
  minesweeper-bot

docker logs -f minesweeper-bot
```

`Dockerfile` در ریشهٔ پروژه هست و آمار را در `/data/stats.json` می‌نویسد.

</details>

<details>
<summary><b>🧩 systemd (VPS لینوکس)</b></summary>

```ini
# /etc/systemd/system/minesweeper-bot.service
[Unit]

After=network-online.target
Wants=network-online.target

[Service]

Restart=always

[Install]

```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now minesweeper-bot
journalctl -u minesweeper-bot -f
```

</details>

<details>
<summary><b>☁️ سرویس‌های PaaS (Railway / Render / Fly.io / ...)</b></summary>

- نوع سرویس: **Worker** (نه Web) — ربات با long-polling کار می‌کند و پورت باز نمی‌کند.
- Start command: `python bot.py`
- متغیر محیطی: `BOT_TOKEN=...`
- اگر سرویس **دیسک موقت** دارد، آمار با هر ری‌استارت پاک می‌شود؛ یک volume به
  `/data` وصل کن و `--stats-file /data/stats.json` بده.
- ⚠️ سرویس‌هایی که فایل‌سیستم‌شان read-only است به volume نیاز دارند، وگرنه ثبت آمار خطا می‌دهد.

</details>

> ⚠️ **فقط یک نسخه را همزمان اجرا کن.** اگر دو نسخه با یک توکن اجرا شوند، تلگرام خطای
> `409 Conflict` می‌دهد.

## 📁 ساختار پروژه

```text
bot/
├── bot.py               # منطق ربات: دستورها، لابی دوئل، نوبت‌ها، حلقهٔ long-polling
├── duel.py              # منطق خالص دوئل: نوبت‌گردشی، برد/باخت، تسلیم، دوئل مجدد
├── minesweeper.py       # منطق تخته: کاشت مین، flood-fill، chord، اولین کلیک امن
├── ui.py                # متن‌ها و صفحه‌کلیدها (دوئل، تک‌نفره، جدول امتیازات)
├── telegram_api.py      # پوشش نازک روی Bot API با urllib
├── storage.py           # ذخیرهٔ آمار: تک‌نفره + جدول و تاریخچهٔ هر گروه (JSON اتمیک)
├── fa.py                # رقم‌های فارسی، زمان و تاریخ فارسی
├── tests/               # ۱۱۵ تست: منطق، جریان، ذخیره‌سازی و اعتبارسنجی HTML
├── run.bat / run.sh     # اجرای سریع (ویندوز / لینوکس-مک)
├── token.txt.example    # نمونهٔ فایل توکن (این را به token.txt کپی کن)
├── requirements.txt     # خالی است — هیچ وابستگی خارجی لازم نیست
├── Dockerfile           # تصویر داکر آماده
└── stats.json           # آمار — خودکار ساخته می‌شود و در git نیست (اینجا فقط نشان داده شده)
```

**معماری در یک نگاه:** منطق بازی (`minesweeper.py`، `duel.py`) هیچ وابستگی‌ای به
تلگرام ندارد و کاملاً قابل تست است؛ `ui.py` فقط متن و دکمه می‌سازد؛ `bot.py` این‌ها را
به رویدادهای تلگرام وصل می‌کند؛ `storage.py` تنها جایی است که روی دیسک می‌نویسد.

تست‌ها با یک **API جعلی** اجرا می‌شوند؛ نه توکن لازم دارند و نه اینترنت.

پوشش تست‌ها: نوبت‌گردشی، رد کردن حرکت بازیکنِ غیرنوبت و تماشاچی، امتیاز بمب (نوبت
اضافه)، پایان بازی با پیدا شدن همهٔ مین‌ها، تایم‌اوت ۱۰ دقیقه‌ای و مساوی، تسلیم،
دوئل مجدد، چند دوئل/دعوت همزمان در یک گروه، انقضای دعوت‌نامه، جدول و تاریخچهٔ گروه،
escape شدن نام‌های خطرناک و اعتبار XML/HTML همهٔ متن‌های ارسالی.

## 🛠 توسعه

### افزودن سطح جدید

فقط یک خط در `minesweeper.py`:

```python
DIFFICULTIES["expert"] = Difficulty("expert", "حرفه‌ای", 9, 9, 25)
```

> سقف تلگرام **۱۰۰ دکمه** در هر صفحه‌کلید است؛ زیر ۱۰۰ خانه بمان.

### نکات کد

- کد با `from __future__ import annotations` و type hint نوشته شده؛ بدون وابستگی خارجی بمان.
- هر متن ارسالی به تلگرام باید HTML-escape شود (`ui.py` را ببین) — تست `test_rendering.py` این را چک می‌کند.
- منطق خالص بازی را در `minesweeper.py` / `duel.py` نگه دار تا بدون تلگرام تست شود.
- قبل از ارسال PR، تست‌ها را اجرا کن: `python -m unittest discover -s tests -t .`

## 🩺 عیب‌یابی

| مشکل | راه‌حل |
| --- | --- |
| `توکن ربات پیدا نشد` | توکن را با `--token`، متغیر `BOT_TOKEN` یا فایل `token.txt` بده |
| `401 Unauthorized` | توکن اشتباه است؛ از BotFather توکن تازه بگیر (`/revoke`) |
| `409 Conflict` | نسخهٔ دیگری از ربات در حال اجراست (یا وبهوک فعال است)؛ آن را ببند |
| در گروه جواب نمی‌دهد | ربات را دوباره اضافه کن و **دستور** بزن (`/duel@YourBot`)؛ دکمه‌ها همیشه کار می‌کنند |
| «این دکمه مال پیام/نسخهٔ قبلی ربات است...» | ربات آپدیت یا ری‌استارت شده و آن بازی در حافظه نیست؛ `/duel` تازه بزن |
| ربات در تاپیک اشتباه جواب می‌دهد | در تاپیک دلخواه (مثلاً چت آزاد) دستور `/topic` را بزن (مدیر گروه) |
| دکمه‌ها قدیمی شده‌اند | پیام قدیمی را رها کن و `/duel` تازه بزن |
| متن فارسی در کنسول ویندوز خراب است | `chcp 65001` یا از `run.bat` استفاده کن (خودش UTF-8 را ست می‌کند) |
| آمار ذخیره نمی‌شود | مسیر `--stats-file` باید قابل نوشتن باشد (در داکر: volume روی `/data`) |

## 🔐 امنیت

- 🔑 `token.txt`، `.env` و `stats.json` در `.gitignore` هستند و **نباید** منتشر شوند.
- 🚨 اگر توکن جایی لو رفت، در BotFather با `/revoke` توکن تازه بگیر و `token.txt` را به‌روز کن.
- 🧼 همهٔ نام‌ها/عنوان‌های گروه قبل از ارسال HTML-escape می‌شوند؛ اما اگر ربات را
  دستکاری کردی، این قانون را نشکن.
- 📊 `stats.json` شامل **آی‌دی عددی کاربران تلگرام** و نام‌هایشان است. اگر آن را منتشر
  می‌کنی، اول پاکش کن — این یک دادهٔ شخصی است.
- 🐳 در داکر توکن را با `-e BOT_TOKEN=...` بده، نه با کپی کردن `token.txt` داخل ایمیج.

## 🇬🇧 English Summary

**Telegram Minesweeper Bot** — a zero-dependency (standard library only) Telegram bot
with two modes:

- ⚔️ **Two-player duel** in groups: both players share one board and take turns.
  Hitting a mine scores a point **and keeps the turn**; revealing a safe cell passes
  the turn. Most bombs wins. Results are stored in a **per-group leaderboard** with
  head-to-head records.
- 🎮 **Single-player** Minesweeper with three difficulties, flag mode, chording and
  personal best times.

**Features:** atomic JSON stats, concurrent duels/lobbies per group, 15-minute lobby
TTL, 10-minute idle timeout, surrender, rematch, forum-topic support, multi-threaded
update handling, Persian UI, and 115 unit tests that need no token or network.

**Quick start:**

```bash
git clone https://github.com/arshiaeliasy/telegram-minesweeper-bot.git && cd telegram-minesweeper-bot
echo "123456:ABC-DEF..." > token.txt   # token from @BotFather
python bot.py
```

Requires **Python 3.9+** and nothing else. See the
[commands table](#-دستورها) and the [deployment section](#-دیپلوی) above.
